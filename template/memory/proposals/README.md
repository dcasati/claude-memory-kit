# Proposals (to be approved by a human)

This is where the following land:
- **dreaming proposals** (`YYYY-MM-DD-dreaming.md` files): each proposal
  comes with its evidence (session excerpts) and its statistics
  ("seen 4 times across 6 sessions");
- **agent proposals** to change the shared memory `memory/organization/`
  (which it is not allowed to touch directly).

## How to approve

1. Open the proposals file.
2. For each proposal, replace `[ ]` with `[OK]` (accept) or `[NO]` (reject).
3. Run `copilot` then type `/dreaming apply`: only proposals marked `[OK]`
   are applied; the file is then archived with a `-done.md` suffix.

Nothing is applied automatically: **you decide** (an explicit recommendation
from the talk: dreaming proposes, the human decides).
